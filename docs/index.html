05 / FAQ

你可能还想知道。

关于窗口、权限和后台运行的一些常见问题。

Arrwin 会不会改变窗口大小？ +
不会。默认排列只调整窗口位置。完全重叠时，可以按需开启“错开标题栏”，让每个窗口的标题栏更容易被点到。
关闭主窗口后，它还会继续运行吗？ +
会。最小化或关闭主界面后，Arrwin 会隐藏到系统托盘，遮挡监控和 Ctrl 悬停提升仍可继续工作。双击托盘图标可以重新打开主界面。
为什么有些窗口没有被排列？ +
全屏窗口和小于 200 × 200 像素的窗口会被自动过滤。部分受系统保护的高权限窗口也可能无法移动，可以尝试以管理员身份运行。
支持哪些 Windows 版本？ +
Arrwin 面向 Windows 10 和 Windows 11。界面会跟随系统明暗模式，并针对 Windows 11 的 Sun Valley 视觉风格做了适配。
设置保存在哪里？ +
设置保存在程序目录下的 config.json 中。你可以在界面里修改，也可以关闭程序后直接编辑文件；缺少配置项时会自动使用默认值。
